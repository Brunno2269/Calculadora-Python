# Calculadora Tkinter

## Descrição
Aplicativo de calculadora criado em Python com interface gráfica utilizando a biblioteca Tkinter. A aplicação oferece funcionalidades básicas de cálculo, como soma, subtração, multiplicação e divisão.

## Requisitos
Antes de rodar o aplicativo, verifique se você tem o Python 3.7 ou superior instalado no seu sistema. Além disso, você precisará da biblioteca `Tkinter`, que geralmente vem instalada junto com o Python.

### Para verificar se o Python está instalado corretamente:

python --version
